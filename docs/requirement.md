# HotSpot 项目需求说明

## 1. 项目简介

HotSpot 是一个知乎热点观察与议题速览助手，旨在获取知乎热点内容，并通过本地分类、搜索和筛选等功能，帮助用户更方便地浏览和整理热点信息。

目前项目已完成基础网页原型，并支持通过官方 Zhihu CLI 获取实时热榜；未安装 CLI 或未配置 Access Secret 时仍可使用演示数据模式。

## 2. 核心功能

1. **热点展示**：以列表或卡片形式展示热点标题、排名、摘要和原文链接。
2. **热点分类**：根据标题和摘要中的关键词，将热点划分为科技、教育、社会、生活、其他等类别。
3. **分类统计**：统计不同类别的热点数量，帮助用户了解当前热点分布。
4. **分类筛选**：用户可以选择某个类别，只查看对应热点。
5. **关键词搜索**：根据关键词筛选热点标题和摘要。
6. **原文跳转**：点击热点后，可以跳转到知乎对应内容。
7. **数据更新**：通过官方 `zhihu-cli hot --limit 20` 获取真实热点，成功采集后展示采集时间；演示数据不显示虚假的采集时间。

## 3. 技术方案

- Python：主要开发语言。
- Streamlit：网页界面。
- 知乎 CLI：后续用于获取知乎热点数据。
- GitHub：代码托管与团队协作。
- AI Works：计划使用的部署平台。
